# 真实项目复盘：10 秒手势框角色转绘

- 复盘日期：2026-08-12
- 运行版本：0.6.0
- 经验入库版本：0.7.0
- 人工结论：用户在内置浏览器确认审核，并评价“这次做得非常好”。

## 已验证链路

1. 原始人物视频非破坏性裁成 10 秒输入，源文件哈希保持不变。
2. 用户手动生成并回传一条原创漫画角色转绘视频；没有可验证的生成平台任务 ID、模型页面或 credits 记录。
3. 同一裁后原片用于跟踪、项目和最终合成。
4. 浏览器 MediaPipe 以 6 fps 采样，63 帧中 62 帧可见；阶段为 line 10、opening 9、open 42、held 1、absent 1。
5. 手框采用全画面对齐转绘层加动态 Alpha 遮罩，不使用四点透视。
6. 最终成片 10.0 秒、1080×1920、30 fps、H.264/AAC，自动验证全部通过。
7. 用户完成最终视觉审核并明确确认。

## 从失败到通用规则

| 现场问题 | 根因 | 入库规则 |
|---|---|---|
| 现有角色生成被版权策略拦截 | 把命名 IP 直接当生成目标 | 只保留题材方向，生成原创角色与原创环境。 |
| Provider 只支持整数秒 | 原片时长与模型档位不一致 | 生成独立整数秒输入，并将其作为全流程唯一时间基准。 |
| 审核页白色圆点无法拖动 | 竖版画布的视觉尺寸和指针坐标系不一致 | 指针必须相对画布真实可见矩形换算。 |
| 框内画面被扭曲 | 把转绘片做了四点透视 | 转绘层全画面对齐，四边形只做可见性遮罩。 |
| 风格画面突然出现 | 用面积/张开阈值做二元开关 | 双手存在即保留近退化细线，并连续展开。 |
| 闭合手势面积接近零 | 指尖几乎落在同一条线上 | 保持语义指尖顺序，只增加最小可渲染厚度；真实旋转产生的自交不得排序或凸包化。 |

## 不外推的部分

- 96.83% 覆盖率只属于本条原片，不是通用准确率。
- “Seedance 2.0”来自用户说明，因为缺任务凭证而不记为 provider-backed 模型证据。
- 用户好评证明本条成片达到其目标，不证明其他人物、动作、模型或商业用途同样成功。
