# 生产成功手册

这份手册来自两轮真实人物视频测试：一条 10 秒单转绘成片得到用户确认；一条 11 秒、五转绘轮换项目完成审核、渲染和自动验证。它提高成功率，但不把少量样本包装成跨人物、跨动作或跨模型保证。

## 一、生成前先锁定唯一时间基准

1. 先查清 Provider 支持的离散时长，再生成请求；不要先生成、后补裁片。
2. 原片时长不匹配时，用 `prepare_integer_source.py` 新建整数秒副本，绝不覆盖源文件，也不靠变速凑时长。
3. 同一份裁后原片必须贯穿转绘请求、手部跟踪、审核项目和最终合成。任何阶段换回未裁原片都会造成时序漂移。
4. 首次只生成一个样本。人物、动作、环境和对齐通过人工观看后，才考虑更多版本，避免重复消耗。
5. 多角色模式下，每个风格都生成与唯一原片等长的完整视频；任何一条都不能只生成它在成片里显示的 1–2 秒片段。

## 二、把生成任务写成“对齐转绘”，不是重新创作镜头

Provider 请求必须同时约束：

- 保持原片时长、9:16 画幅、摄影机、景别、构图、人物位置、动作节奏、手指轨迹和口型时序。
- 只改变人物造型、材质、光影和与原创角色一致的环境美术；环境可以重绘，但不能改变空间结构或遮挡手部。
- 角色替换型方案可以显著改变脸型、五官气质、发色、发型、妆容、服装和身份；“对齐”指动作骨架、人物占位、头肩锚点、双手指尖、镜头和时序对齐，不等于保留同一张脸。
- 禁止新增镜头、切镜、推拉摇移、重新取景、慢动作、循环和画面内文字。
- 命名 IP 只在本地作为意图信号，提交前改写为原创角色原型；角色、标志、经典配色和精确服装设计不得进入 Provider 提示词。
- 生成平台若拒绝相似性，不绕过限制；继续拉开面罩、徽章、配色、材质和环境符号的差异，或停止。

环境不是独立装饰。原创都市漫画英雄应配合都市天台、街区或图像小说式城市空间；原创装甲英雄可使用原创科技设施或工业环境。环境变化必须服务角色方向，同时服从原片构图与动作对齐。

## 三、收到转绘片后先拒绝明显错片

自动 QA 通过只说明媒体合同大致成立。人工至少观看：

- 人物身份和原创角色方向是否正确，是否误出现可识别的现有 IP 特征。
- 原片与转绘片的人物位置、身体轮廓、双手和手指是否逐段对齐。
- 摄影机、景别和背景空间是否被重构到无法叠放。
- 脸、手、服装和背景是否闪烁、融化、增删物体或突然跳变。
- 时长、首尾动作和声音时间轴是否一致。

人物错位不能靠透视拉伸或手框遮掩修复，应重新生成。若平台记录可取得，保存模型、任务 ID、运行 ID、链接和 credits；无法取得时明确写 `missing evidence`。

## 四、手势轨迹保留真实展开过程

- 双手同时存在时，使用两侧食指尖和拇指尖形成四角，不设置“必须张到足够大才显示”的面积或距离门槛。
- 只有近零面积的闭合手势需要沿原有语义连线增加约 0.6% 画幅的最小厚度，随后连续进入 `line → opening → open`；已经形成自交的旋转四角不得排序、凸包化或改成细线。
- 四角必须始终使用语义身份顺序：左手食指尖、右手食指尖、右手拇指尖、左手拇指尖。手部旋转时，上边与下边可能真实交叉并形成蝴蝶结式自交路径；这是应保留的动作，不得按几何角度排序、凸包化或循环重编号。
- 用户反馈“抽搐”时先看原片：如果食指与拇指上下关系正在交换，应保留自交并只平滑每个语义点自己的坐标；只有原片没有对应动作的单帧大跳才是检测尖峰。
- 短暂丢检可保持上一几何状态不超过约 0.6 秒；持续缺失才进入 `absent` 并关闭窗口。
- 6 fps 是慢速展开动作的已验证起点，不是固定上限。快速手势、强遮挡或运动模糊时提高采样率，并重新观看插值后的轨迹。
- 检测覆盖率只是诊断信号，不能代替观看。无论覆盖率多高，都要检查细线、展开、完全展开和后段移动。

## 五、预览与渲染必须是同一种画面语义

- 原片和转绘片始终全画幅、同位置、同时间播放。
- 手部四边形只控制转绘层的 Alpha 可见区域。
- 只允许 `fit_mode=clip`，不做四点透视，不循环转绘片。
- 多条转绘片共享全局播放头：成片 6.2 秒切到第三种角色时，直接读取第三条转绘片的 6.2 秒，而不是它的 0 秒。
- 角色轮换默认从手框首次完全展开时起算，把剩余可见时长平均分配给所有角色；每段目标为 1–2 秒，边界使用约 0.12 秒短交叉淡化，最后一条保持到结尾。
- 审核页和渲染器必须读取同一份轨迹、开合状态和配置；不能预览正确、成片又走另一套逻辑。

## 六、双重人工闸门与最终抽查

确认前必须同时完成：

1. 用户已逐条完整观看并接受全部转绘片。
2. 用户已检查可拖动四角、轨迹和动态遮罩效果。

渲染后不能只看技术报告。至少抽查五类时刻：双手缺失、细线、展开中、完全展开、后段移动。检查窗口外始终为原片，窗口内人物与背景同位置切换，没有突然整块出现、压扁、拉斜或循环跳变。

多角色还要增加两项门禁：自动计算所有转绘片两两抽样帧的像素差异，防止误把同一文件或几乎相同结果当成多个风格；人工逐条判断人物身份与审美是否真正有区分。自动像素差异只是低成本代理，不能证明角色设计质量。

若轨迹含自交关键帧，渲染报告必须记录固定语义角点顺序、自交帧数和时刻；最终验证要求这些关键帧在渲染阶段仍产生自交帧。再抽查交叉前、交叉中、交叉后三个画面，防止检测器、插值器或渲染器偷偷把它恢复为凸四边形。

## 七、失败分流

| 现象 | 处理 |
|---|---|
| Provider 只接受整数秒 | 先裁出新输入，并让该文件贯穿后续流程；不拉伸速度。 |
| 命名角色触发版权限制 | 改成同题材的原创原型，并同步重做角色与环境设计。 |
| 转绘人物与原片错位 | 拒绝转绘片并重新生成；不靠透视变形补救。 |
| 风格画面突然出现 | 去掉面积/张开门槛，保留近退化细线几何。 |
| 闭合手势面积接近零 | 保留语义点顺序，只增加可渲染的最小厚度。 |
| 旋转动作形成四角自交 | 保留固定指尖连接与蝴蝶结路径；不得排序、凸包化或循环重编号。 |
| 旋转时上、下边交叉消失 | 检测器错误地把四点按几何角度重排成凸四边形；恢复固定指尖身份顺序并允许自交路径。 |
| 原片无对应动作但单点突然跳动 | 只对该语义角点的局部时间段去尖峰并轻量平滑，不重排四点、不全片锁框。 |
| 竖版审核页手柄无法拖动 | 用画布真实可见矩形换算指针坐标，并扩大命中区域。 |
| 快速动作跟踪断裂 | 提高采样率，缩短保持窗口后重新审核；必要时人工关键帧。 |
| 缺 Provider 任务证据 | 可以继续做本地人工回传项目，但报告必须标记非 provider-backed。 |

## 八、证据边界

已验证的是：一条真实 10 秒人物视频的单转绘完整成片与用户确认；另一条 11 秒、720×1280、24 fps 人物视频的五转绘全局时间轮换、两两视觉差异代理、旋转自交保留和技术验证。第二条最终成片尚未取得渲染后用户视觉确认。尚未验证的是跨人物/跨动作稳定性、快速或严重遮挡手势、平台模型身份、credits、商业权利、长视频、4K/HDR/VFR 和跨平台安装。
