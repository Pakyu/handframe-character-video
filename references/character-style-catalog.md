# 角色与画面风格规则

## 1. 选择来源

角色和画面风格必须由用户明确选择。画面分析可以判断人数、主体大小、入镜完整度、遮挡、运动和镜头条件，但不得判断性别、性别身份、年龄、族裔或其他敏感属性。

用户要求“检测男女后自动匹配”时，明确说明无法执行外表性别推断，并提供角色版本选择。默认不偷偷选择。

## 2. 现有 IP 的原创化路由

- 用户提到现有 IP 时，不向 Provider 提交该名称，也不要求复刻其标志、经典配色、服装、道具或可识别剪影。
- 蛛网/都市英雄类请求映射为 `original-urban-comic-hero`：原创蒙面都市英雄、原创几何纹样、非经典红蓝配色、经典美式漫画的一般视觉语言。
- 动力装甲类请求映射为 `original-armored-hero`：原创装甲结构、非经典红金配色、非圆形能源结构和原创头盔。
- 映射应保留题材、媒介、氛围、动作能量和环境逻辑，不保留角色身份或受保护的识别性设计。
- 旧版 `marvel-*` style-id 只作为本地兼容别名，`prepare_transform_request.py` 会确定性转换并记录 `ip_reframing_performed=true`。
- 多人物视频：询问全部使用同一主题，还是由用户按“人物 1 / 人物 2”逐个指定；不得自动按外表分配。

## 3. 艺术家与工作室风格

用户说“宫崎骏/吉卜力风格”时，映射为 `warm-handpainted-fantasy-anime`：细腻二维赛璐璐人物、柔和水彩背景、自然光、质朴色彩、富有生命力的风与云、克制真实的表演。生成指令不得要求复制在世艺术家或具体工作室的独特画风。

其他艺术家命名请求同样拆成媒介、色彩、线条、光线、构图、运动和情绪等一般特征；无法安全转译时询问用户。

## 4. 原创边界

- Provider 请求只允许 `original-archetype` 或 `descriptive-style`。
- 角色原创不等于自动获得商业清权；品牌、素材、音乐和真人肖像等其他权利仍需单独确认。
- 如果平台仍因相似性拒绝，继续降低识别性设计：更换配色、徽章、面罩结构、材质和环境符号；不得绕过平台限制。
- 不声称与任何影视、漫画、游戏公司、艺术家、工作室或权利人存在合作、授权或背书。

## 5. 多角色差异化

- 用户要按 1–2 秒轮换多个转绘角色时，优先使用 `replace-character-preserve-motion-anchor` 类型。
- 每个方案必须至少在脸型、发色/发型、妆容、服装轮廓、材质和角色身份中形成多项显著差异，不能只是换配色或背景。
- 对齐约束落在头部中心、肩线、躯干中心、身体比例、双手与指尖坐标、动作、口型节奏、镜头和空间透视；不把“面容身份保持”写进替换型提示词。
- 每个角色匹配自己的环境美术，但环境仍同构保留原片的墙面、门窗、家具和纵深坐标。

## 6. QA

自动 QA 只证明媒体可读、时长/比例基本一致、画面发生变化和证据链完整。必须人工检查：原创角色方向是否符合选择、不同角色是否一眼可区分、是否意外出现现有 IP 识别特征、人物数量、动作、口型、镜头、脸/手/肢体稳定性、闪烁、增删物体、文字和水印。
